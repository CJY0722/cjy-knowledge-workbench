# CJY 知识工作台微信小程序

这是与现有网页并列的原生微信小程序，不替换网页或本机桥接。

## 当前可用功能

- 手机微信与电脑微信自适应布局。
- 从微信会话导入 Markdown / TXT 文件。
- 本地知识检索、任务提取、文章阅读。
- 新建和修改博客草稿、复制 Markdown。
- 数据只保存在当前设备的微信小程序存储中。

## 打开项目

1. 启动微信开发者工具，选择“小程序 → 导入”。
2. 项目目录选择本文件所在目录 `wechat-miniprogram`。
3. 把 `project.config.json` 的 `appid` 换成自己的测试号或正式小程序 AppID；仓库中的 AppID 只用于本地开发示例，不包含账号权限。
4. 点击编译即可运行。

当前测试号可在开发者工具中完成编译和模拟器测试，但不能代替正式小程序账号提交审核。准备发布时，需要在微信公众平台注册正式小程序、替换 AppID，再使用开发者工具的“上传”功能提交版本。
