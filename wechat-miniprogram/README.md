# CJY 知识工作台微信小程序

这是与现有网页并列的原生微信小程序，不替换网页或本机桥接。项目已经绑定正式小程序 AppID，可在管理员登录后上传审核版本。

## 当前可用功能

- 手机微信与电脑微信自适应布局。
- 从微信会话导入 Markdown / TXT，编辑后导出回自己的 Obsidian。
- 本地知识检索、Markdown 任务识别与状态更新、剪藏收件箱。
- WikiLink 关系与失效链接检查、孤立/长期未更新笔记回顾。
- 博客新建、修改、发布检查，以及 CSDN、掘金、知乎、微信公众号和小红书物料转换。
- 小红书长文转换为纯文本，并切成最多 18 页的图卡内容预览。
- 发布完成确认后清空编辑区，不删除本地知识库里已保存的文章。
- 每位用户的数据只保存在自己的微信设备中，不会连接或共享维护者的 Obsidian。

## 打开项目

1. 启动微信开发者工具，选择“小程序 → 导入”。
2. 项目目录选择本文件所在目录 `wechat-miniprogram`。
3. 使用正式小程序管理员微信扫码登录。
4. 点击编译即可运行。

## 发布前必须完成

1. 在微信公众平台补全小程序名称、头像、简介、服务类目和隐私保护指引。
2. 在微信开发者工具完成手机预览与真机测试。
3. 使用“上传”生成开发版本，再到微信公众平台提交审核；审核通过后仍需管理员手动发布。
4. 当前不采集手机号、位置、通讯录或维护者知识库内容；若以后新增云同步或 AI，必须先更新隐私说明。

## 尚未接入

跨设备同步和 DeepSeek 仍需先在正式小程序下创建微信云开发环境。真实 API Key、AppSecret 和知识库凭据不得写进小程序源码；在云环境接入前，所有不依赖网络的知识管理与平台物料功能均可使用。
