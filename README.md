# CJY 知识工作台

这是合并后的本地工作台：保留原 CJY 知识管理、任务、回顾、剪藏与知识图谱，并加入按写作规范执行的博客工作流。

## GitHub Pages

仓库包含独立的静态构建和 GitHub Actions 发布流程。推送到 `main` 后会自动部署公开演示页面：

```powershell
npm run build:pages
```

公开页面只展示工作台界面。浏览器不能读取本机 `E:\ObsidianVault`，知识检索、草稿写入和 CSDN 发布准备仍需在本机同时运行网页与桥接服务。

## 启动

需要 Node.js 22.13 或更高版本。分别在两个终端运行：

```powershell
node bridge.mjs
```

```powershell
npm run dev -- --hostname 0.0.0.0 --port 3000
```

然后打开 `http://127.0.0.1:3000/#blog`。本地桥接固定使用 `http://127.0.0.1:8766`，并校验知识库为 `E:\ObsidianVault`。

## 博客流程

1. 选择“AI 从知识源写作”或“已有文章 AI 辅助修改”。
2. 完成五类知识预检，并选择参考笔记。
3. 确认重点后生成或修改草稿；发送内容给 OpenAI 前会再次确认。
4. 运行结构、图示宽度、长文与去 AI 痕迹检查。
5. 明确确认后保存 Markdown，再生成 CSDN / 小红书发布文案。
6. 预览并确认复盘条目后，才会回写 Obsidian 元知识与写作事件日志。

五类预检会读取对应元知识，并沿博客索引加载相关旧文片段作为风格参考。元知识或事件日志即将超过 200 行或 10,000 字符时，桥接会按月份自动分篇。

## 安全边界

- 不读取或保存 CSDN Cookie、密码、Token，也不替用户点击最终发布。
- CSDN 功能只负责净化 Markdown、复制标题和正文、打开官方编辑器。
- PDF、图片等视觉材料需要先由用户完成渲染或 OCR，在界面中填写核验记录并明确确认后才能继续。
- 浏览器只保存当前会话草稿；长期知识只写入 Obsidian。
- 桥接只接受来自本机 `localhost:3000` 或 `127.0.0.1:3000` 的网页请求。
- “重扫知识库”是文件扫描，不宣称存在向量索引。
